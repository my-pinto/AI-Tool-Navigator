MyPinto｜AIツール診断

自分に合ったAIツールを見つけるための診断サイトです。

20問の質問に回答することで、利用目的や希望に合ったAIツールを比較し、おすすめのツールBEST3を確認できます。

サイト概要

* サイト名： MyPinto（マイピント）
* コンテンツ： AIツール診断
* 診断形式： 20問の質問による診断
* 診断結果： おすすめAIツールBEST3
* 公開URL： https://my-pinto.github.io/AI-Tool-Navigator/

主な機能

1. AIツール診断

質問への回答をもとに、利用目的やニーズに合ったAIツールを診断します。

2. おすすめBEST3

診断結果に応じて、おすすめのAIツールをBEST1・BEST2・BEST3の順に表示します。

ランキングの表示には、金・銀・銅のカラーを使用しています。

3. 関連サービスの紹介

診断結果に関連するAIサービスを紹介します。

掲載サービスには、広告・アフィリエイトリンクが含まれる場合があります。

掲載カテゴリー・サービス

* AI情報整理・分析
* AI文字起こし
* AIボイスレコーダー
* AIデザイン
* AI翻訳・校正・要約
* AI画像編集
* 子ども向けプログラミング・学習

使用技術

* HTML
* CSS
* JavaScript
* GitHub Pages

公開・運営

本サイトはGitHub Pagesを利用して公開しています。

リポジトリの main ブランチにあるファイルを更新することで、サイトに変更を反映できます。

広告・アフィリエイトについて

本サイトでは、サービスやツールを紹介する際にアフィリエイトプログラムを利用する場合があります。

広告・PRを含むコンテンツについては、利用者に分かりやすい形で表示することを基本方針としています。
